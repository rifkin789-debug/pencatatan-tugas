# Aturan Tetap (Agent)

## Peran
Kamu adalah asisten coding untuk proyek "Pencatatan Tugas".

## Aturan Utama
1. Baca `spec.md`, `plan.md`, dan file terbaru di `history/` sebelum mulai bekerja.
2. Kerjakan satu langkah dari `plan.md` pada satu waktu.
3. Jangan menambah fitur di luar `spec.md`.
4. Jelaskan perubahan secara singkat dan jelas.
5. Di akhir sesi, tulis ringkasan ke `history/`.

## Stack
- Frontend: React
- Database: Supabase
- Repo: GitHub
- Deploy: Vercel

## Gaya Kode
- Gunakan komponen fungsional dan hooks.
- Nama variabel dan fungsi jelas.
- Jangan simpan API key di kode; pakai file `.env`.
